## Project Overview

Automated Solana meme coin scalping bot ("MemeBot") built as a set of n8n workflows running on a Dockerized VPS (Hostinger). The bot scans for new tokens, executes trades, monitors positions, and logs results. Currently in **dry-run/simulation mode** — no real SOL is spent yet.

## Architecture

Four n8n workflows operate as a pipeline, communicating via webhooks and a shared state file (`/tmp/memebot_position.json` on VPS):

1. **WF1 — Token Scanner** (cron every 2 min): Fetches new Solana tokens from Dexscreener API, filters by entry criteria (mcap 30k–100k, liquidity >= $10k, age 5min–6h, volume thresholds).
2. **WF2 — Trade Executor** (webhook from WF1): Simulates buy via Jupiter API v6, writes position state to shared file.
3. **WF3 — Price Monitor & Exit** (cron every 30s): Compares current price to entry, triggers sell on TP (+10%) or SL (-12%).
4. **WF4 — Profit Sweeper & Logger** (webhook from WF3): Logs trade to GitHub (JSON format), cleans up state file.

The workflow JSON files (`WF1 Token Scanner.json`, etc.) are the canonical source — they are imported directly into n8n on the VPS.

## Key Files

- `WF*.json` — n8n workflow definitions (import into n8n, do not run locally)
- `index.html` — Self-contained trade dashboard (Chart.js), fetches trade logs from GitHub raw URLs
- `parse_trades.js` — Node.js script to convert `trades.md` into per-date JSON files in `trades/`
- `trades/` — Daily trade log JSONs (gitignored, generated by `parse_trades.js`)
- `.env` — Contains `GITHUB_TOKEN` (gitignored, used for pushing logs from VPS)

## Commands

```bash
# Parse trade markdown into JSON files
node parse_trades.js

# Serve dashboard locally (any static server works)
npx serve .
```

## Important Context

- **DRY_RUN mode**: Controlled by variable in n8n workflows. Do not switch to live trading without confirming Solana transaction signing is properly implemented.
- **Secrets**: Never commit private keys or seed phrases. Credentials live in n8n credential store or Docker env vars on the VPS, not in workflow JSON exports.
- **Language mix**: Project docs and n8n node names use a mix of French and English.
- **Single position**: The bot holds at most one position at a time (enforced by the state file).
